What's for Dinner?

What's for Dinner? is a responsive meal-planning web application designed to simplify the process of deciding what to cook, organizing family meals, and reducing food waste. Users can discover recipes based on ingredients they already have at home and receive AI-generated meal recommendations tailored to their preferences, dietary needs, and household requirements. The platform helps eliminate the stress of daily meal decisions while making it easier to create balanced and practical meal plans.

The application includes features such as ingredient-based recipe filtering, family profile management, household meal planning, a shared meal calendar, and automatically generated grocery lists based on scheduled meals. Built using modern web technologies, the project demonstrates experience in responsive user interface design, state management, AI integration, and creating user-focused solutions that solve real-world problems for individuals and families.

Waggle was my Engineering Capstone project, developed alongside three classmates. We built a web-based visual programming platform for designing, simulating, and testing swarm robotics environments without requiring low-level robotics code.

The application enabled users to create complex robot behaviors through an intuitive drag-and-drop interface while visualizing real-time swarm interactions and simulations.
